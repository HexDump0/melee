# S2 render + boot log (P-606)

Captured 2026-09-12 with the S2 GX HLE in place. The prototype is untouched.

## Boot triage (GX is now a real backend)

```
./build/native/melee_decomp_boot --boot-frames 10 --boot-timeout 30 \
    --boot-log /tmp/boot-s2.log
```

```
[boot] summary: frames=10 stub_calls=94 unique=33
[boot] STOP: frame budget reached
```

The 146 GX calls in 10 frames no longer hit the triage stubs (the command
surface moved to `native/decomp/gx/gx_hle.c`); only `GXSetDrawDone` remains in
the "stub" list because it is the real XFB/frame-pacing hook.  The ordered
remaining backend list is unchanged otherwise: DVD/ARQ (S3), AX (S5),
CARD/EXIT+fonts (S6), alarms/threads (S4).  See
`2026-09-11-S1-boot-triage.md` for the per-stub detail; the deterministic
boot still stops in the game's own loading wait.

## Compiled HSD + GX render

```
./build/native/test_decomp_render --width 1280 --height 800 \
    --shot /tmp/opencode/compiled.bmp --dump
```

```
decomp_render: PlMrNr.dat root=... scale=1.1000
decomp_render: hidden DObjs=16
decomp_render: bounds [-8.31 -0.31 -2.86] to [8.32 15.44 3.72]
decomp_render: lights=2
gx_gl: GL_VERSION=OpenGL ES 3.2 Mesa 26.1.6-arch1.1
gx_gl: GL_RENDERER=AMD Radeon RX 580 2048SP (radeonsi, polaris10, ACO, DRM 3.64)
decomp_render: draws=52 vertices=17724 textures=88 display_lists=52
               primitives=292 skipped=0 degenerate=1826
decomp_render: wrote /tmp/opencode/compiled.bmp
decomp_render: PASS
```

- 52 draws = 68 PObj display lists minus the 16 hidden DObjs' lists; vertex
  count and material state come from the compiled HSD display path.
- Bounds match `--inspect` except the hidden parts are excluded.
- World bounds without visibility were exactly the prototype's
  `[-8.31 -0.31 -2.97] to [8.32 15.63 3.94]` (scale included), which is the
  geometry-parity check.
