# Session logs

Optional, long-form notes for investigations that are too detailed for
`learnings/`. Use sparingly.

- `learnings/` is for durable facts; logs are for the story of a session.
- Name files `YYYY-MM-DD-<topic>.md`.
- Never paste large game data blobs. A few illustrative hex bytes are fine.
- If a log contains a durable fact, move that fact into `learnings/` and link
  back here.
