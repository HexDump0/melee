# P-648: HPS stream page ring fixed (menu BGM)

Captured 2026-09-13 from the repo root.  Fix commit: the one that adds
`ax_collapse_addr_sync` and the crossing end test.

## Repro

```sh
# /tmp/tomain2.txt: channels 1; 240/300 a; 660 start
SDL_AUDIODRIVER=dummy SDL_VIDEODRIVER=offscreen \
  ./build/native/melee --frontend --no-items \
  --input /tmp/tomain2.txt --frames 1400
```

## Root causes (all gdb-verified)

1. **Coalesced AX sync (G-115).**  The first `__AXServiceVPB` for a stream
   voice before the fix: `sync=0x0007d2b6` = `COPYADDR | COPYCURADDR |
   COPYENDADDR | COPYLOOPADDR | ...` but **no** `COPYLOOP`.  The per-field
   branch wins over the whole-`AXPBADDR` branch, so the shadow's `loopFlag`
   stays 0 while the user PB reads 1.  On hardware the header -> page table ->
   64 KB page data DevCom chain spans several 5 ms AX frames; the host
   completes it inside one frame.
2. **End test must be crossing-based (G-116).**  A `[wrap]` trace showed a
   storm (`frame_addr=... -> loop=...` repeated 12+ times in one AX frame,
   at axframes 2909/3268/3982/4338) because the loop target (next ring slot)
   sits above the stale `endAddress`, so `frame_addr >= end` re-wrapped every
   frame and replayed the page's first frame as a ~2.3 kHz buzz for 5-15 ms.
   The DSP triggers on the address *crossing* the end.
3. **Page-table loop contexts not swapped (G-117).**  `hps_fix_read` only
   swapped the three u32s, so `AXPBADPCMLOOP.loop_yn1/loop_yn2` reached the
   mixer byte-swapped (`[wrap] ... predscale=7700` instead of `0077`).

## Evidence

```

[wrap] axframe=2551 v=61 frame_addr=00c43d42 -> loop=00bf3d42 yn=(2936,4264) predscale=0058
[wrap] axframe=2909 v=60 frame_addr=00c13d42 -> loop=00c23d42 yn=(-4242,-3649) predscale=0056

```

Decoded page data in a throwaway Python probe: the stored `AXPBADPCMLOOP`
context at every page boundary equals the running decoder state exactly
(`pred`, `yn1`, `yn2`; pages 1-11, both voices), so the ring is
sample-continuous.

  ./build/native/melee --frontend --no-items \

both pass; no `src/`, `extern/` or converter-version changes were needed
(the HPS conversion lives in the platform backend).
