# Handoff: P-646 — the card command pump deadlocked on split work-area symbols

**Date:** 2026-09-14
**Agent:** opencode (deepseek-v4.1-flash)
**Commit:** working tree (this commit)
**Tree state:** builds; `ctest --test-dir build/native` 19/19.

## What I did

- Found the deadlock cause: the console's `hsd_804D1148` (CardContext command
  ring, +0x10) and `hsd_804D2348` (dispatch queue, +0x1210) alias inside
  `hsd_804D1138[0x1510]`, but the host allocated all three separately.  Queue
  writers used the context, `fn_803AA790` popped the standalone array, so the
  first file command was never dispatched and `x8AC` waited forever.
- Updated the `hsd_4D11.c` `PORT_PC` patch so only the base is allocated and
  the other two symbols are `__asm__(".set ...")` aliases at +0x10/+0x1210.
- Cards are now inserted by default (a console with a card in slot A);
  `MELEE_NO_CARD=1` simulates an empty slot.  Headless debug-boot tests pin
  `MELEE_NO_CARD=1` so host save data cannot re-route them.
- Added `native/tests/frontend_card.sh` + `ctest decomp_frontend_card`: two
  400-frame frontend runs over one card directory (create then load) that
  require `card_a/file_000.gcm` after both.
- G-132 documents the failure; the patch table in `learnings/decomp_port.md`
  and STATE/TASKS/ROADMAP are updated.

## Exact next action

`ctest --test-dir build/native -R decomp_frontend_card --output-on-failure`
expects `frontend_card: PASS`.  The P-662/P-658 converter work then has to fix
the `dynamicsdata_flag*` publics before the **load** run can reach a full

(`GrCs.dat`) and `grCastle_801CD658 -> lb_8000FD48` walks a big-endian
`DynamicsDesc.count` (0x06000000 instead of 6) into a crash.

## What I tried that did not work

- Deferring mount/check callbacks inline (pre-existing design) — irrelevant;
  the mount/check completions were already delivered through the platform
  completion queue and printed in the trace.
- Only giving `hsd_804D1138` its full size (the G-085 fix) — this stopped the
  out-of-bounds write but not the split queue.
