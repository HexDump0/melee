# Gotchas

Every entry has already cost someone time. Read before debugging; add an entry
when you lose more than 15 minutes to something non-obvious.

Format: `G-NNN`, symptom → cause → fix → evidence. Keep them short. If an entry
becomes obsolete, mark it `RESOLVED` with the commit rather than deleting it.

See [`GOTCHAS.md`](GOTCHAS.md). The template is
[`../templates/gotcha.md`](../templates/gotcha.md).
